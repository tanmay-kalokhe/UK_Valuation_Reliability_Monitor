# Dashboards

The project has two dashboards for two audiences.

| Folder | Tool | Audience | What it shows |
|---|---|---|---|
| `power_bi/` | Power BI Desktop (`.pbip` project) | Analysts, managers, BI teams | A four-page report: market overview, data quality, model performance, reliability monitor |
| `streamlit/` | Streamlit (Python) | Anyone with the link; the interactive demo | Value one property: estimate, price range, main factors, accept-or-refer indicator |

Both read only address-free data. Screenshots of each go in `reports/figures/`.
